# 第一题 数组异或操作
错误：
```python
nums = []  # 空列表，长度为0
        for i in range(n):
            nums[i] = start + 2 * i  # 错误：i从0开始，但nums[0]不存在
```
解决方法：
```python
 nums = []
        for i in range(n):
            nums.append(start + 2 * i)  # 动态添加，避免索引越界
        # 计算异或和
        xor_sum = 0
        for num in nums:
            xor_sum ^= num
        return xor_sum
```
解题思路：把nums先创建出来，然后再循环异或
如何优化？循环可以合并
```python
class Solution:
    def xorOperation(self, n: int, start: int) -> int:
        xor_sum = 0
        for i in range(n):
            num = start + 2 * i
            xor_sum ^= num
        return xor_sum
```

#### `cnt = Counter()`

- **前置依赖**：`Counter` 是 Python `collections` 模块中的工具（代码中隐含了 `from collections import Counter`，LeetCode 会自动导入）；
- **作用**：初始化一个空的 `Counter` 对象 `cnt`。
- 核心特性：`Counter` 是字典的子类，专门用于**统计可哈希对象的出现次数**，键是数字，值是该数字出现的次数（初始为空）。
#### `if x in cnt:`

- **作用**：判断当前数字 `x` 是否在 `cnt` 中（即 `x` 是否在**当前位置之前**出现过）。
- 逻辑：`cnt` 中存储的是 “当前位置之前所有数字的出现次数”，如果 `x` 在 `cnt` 中，说明之前有数字和 `x` 相等，能组成好数对。
#### `ans += cnt[x]`

- **作用**：累计好数对数量。
- 核心逻辑：`cnt[x]` 是 `x` 在 “当前位置之前” 出现的次数，每一个之前的 `x` 都能和当前的 `x` 组成 `i' < i` 的好数对，因此把 `cnt[x]` 加到 `ans` 中。
#### `ans += cnt[x]`

- **作用**：累计好数对数量。
- 核心逻辑：`cnt[x]` 是 `x` 在 “当前位置之前” 出现的次数，每一个之前的 `x` 都能和当前的 `x` 组成 `i' < i` 的好数对，因此把 `cnt[x]` 加到 `ans` 中。
## 主要逻辑就是利用字典来进行统计，键值对（优化思路）
## 我的思路
```python
class Solution(object):

    def numIdenticalPairs(self, nums):

        """

        :type nums: List[int]

        :rtype: int

        """

        sum=0

        for i,num in enumerate(nums):

            for j in range(len(nums)-i-1):

                if num==nums[len(nums)-j-1]:

                    sum=sum+1

        return sum
```
两次循环，抓准次数遍历找配对关系
