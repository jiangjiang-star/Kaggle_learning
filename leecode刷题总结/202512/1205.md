# 第一题 最小偶倍数
思路：
取余,与2的公倍数，按道理说，应该把数值展开，消除相同的因子保留一个。然后乘起来。或者说我记得有辗转相除法？
```python
class Solution(object):

    def smallestEvenMultiple(self, n):

        if n%2==0 # 有2就约掉，再来最小的数值

            return n

        else:

            return n*2
```
